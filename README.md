# Simple Store Management System - Frontend Prototype (React + Vite)

واجهة إدارية عربية RTL احترافية كنقطة بداية لنظام إدارة متجر/شركة، بدون Backend أو API أو قاعدة بيانات حقيقية.

## ✅ ما الذي تم بناؤه؟
- React + Vite + React Router
- RTL كامل باللغة العربية
- تصميم Admin Dashboard حديث (Sidebar + Topbar)
- مكونات قابلة لإعادة الاستخدام داخل `src/components`
- بيانات Mock مفصولة داخل `src/data`
- صفحات المرحلة الأولى المطلوبة (20 شاشة)
- حالات واجهة شكلية: Loading / Empty / Error
- Tabs لتنظيم المحتوى في الصفحات التفصيلية

## الشاشات المتوفرة
1. تسجيل الدخول
2. لوحة التحكم
3. قائمة الأصناف
4. إضافة/تعديل صنف
5. المخزون الحالي
6. حركة صنف
7. إدخال رصيد افتتاحي
8. قائمة الموردين
9. إضافة/تعديل مورد
10. قائمة العملاء
11. إضافة/تعديل عميل
12. قائمة فواتير الشراء
13. إنشاء فاتورة شراء
14. تفاصيل فاتورة شراء
15. قائمة فواتير البيع
16. إنشاء فاتورة بيع
17. تفاصيل فاتورة بيع
18. التقارير الأساسية
19. قائمة المستخدمين
20. إضافة/تعديل مستخدم
