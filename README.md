# نموذج أولي لنظام محاسبة الدهانات وإدارة المستودعات (React + Vite)

واجهة أمامية فقط (بدون Backend) بنمط ERP عربي RTL، قابلة للتوسع لاحقًا.

## المزايا
- React + Vite
- React Router للتنقل بين الصفحات
- تصميم RTL عربي احترافي (Sidebar + Header)
- مكونات قابلة لإعادة الاستخدام (جدول، شارات حالة، بطاقات إحصائية، رؤوس صفحات)
- بيانات Mock مفصولة في ملفات مستقلة
- صفحات أساسية:
  - تسجيل الدخول
  - لوحة التحكم
  - المنتجات
  - المستودعات
  - المخزون حسب المستودع
  - حركات المخزون
  - تحويلات المستودعات
  - الجرد
  - العملاء / الموردون
  - معاينة الفاتورة

## التشغيل محليًا
```bash
npm install
npm run dev
```
ثم افتح الرابط الظاهر في الطرفية (عادةً http://localhost:5173).

## البناء للإنتاج
```bash
npm run build
npm run preview
```
